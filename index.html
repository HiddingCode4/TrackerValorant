Hidding · review prototype

Windows companion and explanatory performance analysis

This HTML is a review companion to the Python desktop prototype. Neither version is connected to Riot or approved by Riot.

Implemented in the desktop prototype

  • Five synthetic teammate profiles.
  • Desktop floating overlay, toggled with Alt + W.
  • Recent match statistics and explained observations.
  • Local JSON import.
  • Simulated account linking, consent and withdrawal.
  • Windows executable build scripts and GitHub workflow.

Requires integration and approval

  • Production VALORANT API access and Riot Sign On.
  • Authorized live lobby identification source.
  • Real consent enforcement and account deletion.
  • HTTPS backend, quotas, secure key storage.
  • Confirmation of permissible overlay phases and analysis.
  • Validation of available rank and match-stat fields.

Data access requested

VAL-MATCH-V1: match list by PUUID and match details by match ID, for authorized profiles. A backend would keep production API keys and RSO secrets outside the executable and repository. Lobby detection is a separate integration question: the documented match-history API does not supply a live agent-select roster.

Performance observations to review explicitly

We propose explained flags for consistently strong performance and recent performance changes. These can be compatible with several causes, including a secondary account or ordinary improvement. They cannot prove cheating or smurfing. We request feedback on acceptability; features may be revised or removed following Riot’s review.

Excluded behavior

No opponent scouting before the match, analysis of deliberately hidden identities, game-memory access, hidden MMR calculation, automated reporting or real-time tactical instructions.

Reviewer walkthrough

  1. Inspect the demo lobby. Nova demonstrates consistent dominance, Echo incomplete history, Lumen a recent ACS increase.
  2. Open a shared profile and inspect its ten-match history.
  3. Preview the team overlay.
  4. Open Account & consent, simulate identity verification, then explicitly enable sharing.
  5. Return to the lobby: Oreo’s fictional statistics become visible.
  6. Revoke consent: those statistics disappear immediately from the lobby and overlay.

Before submission, provide project/contact URLs and production privacy documents. This prototype is evidence of intended behavior, not a complete access application.
